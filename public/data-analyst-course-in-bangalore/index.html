Structured Syllabus

What You Will Learn: Course Curriculum

We teach the tools that entry-level and junior analytics roles ask for, organized in a logical order that makes sense for beginners.

Module 01 Microsoft Excel

Excel for Data Analysis

Most analysts begin and end their day in Excel, so we start there. You will work with formulas, data cleaning, analysis and reporting, and learn how to turn raw data into organised, readable summaries.

  • Essential & advanced formulas (VLOOKUP, XLOOKUP, INDEX/MATCH)
  • Data cleaning, text parsing, and deduplication
  • Pivot Tables, Pivot Charts, and summary metrics
  • Conditional formatting & building readable executive summaries
Module 02 SQL & Relational DBs

SQL and Databases

Business data lives in databases, not spreadsheets. You will learn queries, filtering, sorting, joins and data management, so you can fetch exactly the data you need instead of waiting for someone else to send it.

  • Relational database concepts and schema exploration
  • SELECT, WHERE, GROUP BY, HAVING, ORDER BY
  • Multi-table INNER, LEFT, RIGHT, and FULL joins
  • Subqueries, aggregate calculations, and data filtering
Module 03 Applied Math

Statistics for Analysts

Numbers can mislead. This module builds the statistical understanding needed to read data sensibly, such as knowing what an average hides or when a trend is actually meaningful.

  • Descriptive statistics: Mean, Median, Mode, and Outliers
  • Variance, standard deviation, and data distributions
  • Correlation vs. causation in business contexts
  • Identifying misleading metrics and reporting accurate figures
Module 04 Microsoft Power BI

Power BI & Data Visualization

Insight is useless if nobody understands it. In Power BI you will learn to build reports and interactive dashboards, and how to choose visuals that make the point quickly.

  • Power Query ETL and data modeling basics
  • DAX calculated columns and basic measures
  • Interactive filters, slicers, drill-downs, and bookmarks
  • Designing clean, decision-ready executive dashboards
Module 05 Python for Analytics

Python for Data Analytics

Python is introduced in the context of data work: concepts useful for analysis and for handling datasets. No advanced programming background is expected.

  • Python basics tailored specifically for data handling
  • Working with Pandas DataFrames and NumPy arrays
  • Handling missing values, filtering, and dataset aggregation
  • Exploratory data analysis (EDA) on real-world datasets
Module 06 Tableau Desktop

Tableau Data Visualization

Tableau is widely used by global enterprises for visual discovery and interactive reporting. Learn to connect data, create custom calculated fields, and craft visual stories.

  • Connecting to various enterprise data sources
  • Creating charts, maps, dual-axis graphs, and trendlines
  • Dashboard actions, interactive filters, and parameters
  • Storyboarding and presenting analytical findings clearly
